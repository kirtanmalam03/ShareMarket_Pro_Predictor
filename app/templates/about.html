ABOUT THE PROJECT

About ShareMarket Pro Predictor

ShareMarket Pro Predictor is a high-performance financial intelligence web application engineered by Kirtan Malam. It combines real-time equity market data, technical indicator calculation, and XGBoost machine learning to make stock market trend prediction accessible and actionable.

Mission

Empower retail traders, learners, and quantitative enthusiasts with clear machine-learning insights and real-time market data.

Dual Market Coverage

Seamless real-time quotes and historical features for US equities (NYSE/NASDAQ) and Indian stock markets (NSE NIFTY50).

Modern Technology Stack

Python Flask backend, SQLite database, XGBoost classification, Chart.js dual graphs, Socket.IO streaming, and Tailwind CSS.

How the ML Engine Works

1

Data Ingestion

Historical daily quotes are pulled from yfinance & free Indian API services with memory caching.

2

Feature Engineering

Calculates RSI, MACD, Moving Averages (SMA/EMA), Volatility, ATR, and momentum indicators.

3

XGBoost Inference

Model predicts directional movement (UP/DOWN) and probability confidence score.

4

Portfolio Sync

Selected stocks can be tracked directly in your user portfolio with live P/L calculations.
